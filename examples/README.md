# Project Examples & Sample Outputs

This directory contains pre-generated sample JSON query outputs and execution results, allowing evaluators to evaluate the quality of the system's reasoning and Paritok-powered context reduction metrics without running the backend code.

## Files

- [sample_query_response.json](sample_query_response.json): The full API payload response for a security query targeting the `demo-apt29-compromise` (APT29 SSH Brute Force & Privilege Escalation) dataset.

### Key Metrics to Observe in the JSON:

1. **`paritok_metrics`**:
   - `without_paritok.tokens`: Shows the raw context token size required to hold all retrieved events (typically **12,000+ tokens**).
   - `with_paritok.tokens`: Shows the optimized context size compressed by Paritok (typically **~250 tokens**).
   - `reduction_percentage`: Verification of **95%+ context compression**.
   - `cost_without_paritok` vs `cost_with_paritok`: Demonstration of massive cost reductions.
   - `latency_reduction_ratio`: 4x to 6x speedup in LLM processing time.

2. **`evidence_events`**: The specific log lines identified by Paritok as the high-density evidence pack used to construct the final response.

3. **`answer`**: The grounded security report generated by Groq Llama-3.3-70B using the optimized evidence.
